# AI-Assisted Incident Resolution Platform

Enterprise-grade incident management platform built with **Java (Spring Boot)**, **MySQL**, and modern **JavaScript**, featuring automated priority calculation via design patterns and AI-driven workflow routing.

## Key Highlights & Architecture
- **Backend Architecture:** Developed with Java 17 and Spring Boot utilizing Spring Data JPA for scalable service layers.
- **Design Patterns:** Implements the **Strategy Pattern** for dynamic, decoupled priority calculation rules based on urgency and impact metrics.
- **Relational Data Schema:** MySQL persistence layer featuring optimized indexing on priority and urgency fields for sub-second query performance.
- **Interactive Dashboard:** Responsive frontend built with HTML5, CSS3, and ES6+ JavaScript for live incident queue tracking.

## Tech Stack
- **Language & Framework:** Java 17, Spring Boot
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Build Tool:** Maven
